# EU 14 allergens (Regulation 1169/2011, Annex II) in 6 languages, with menu codes

The 14 allergens restaurants must declare in the EU, named in English, Italian, French, German, Spanish and Portuguese, with short menu codes. CSV, CC BY 4.0.

Free allergen matrix for your menu (no signup), built on this table: https://graziechef.com/en/tools/allergen-matrix?src=github-dataset
